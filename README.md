# Portfolio Ilham Ramadhan

Website portfolio statis untuk **Ilham Ramadhan**, pelajar SMKN 3 Sekayu. Situs ini dibuat memakai HTML, CSS, dan JavaScript biasa sehingga tidak perlu instalasi, build tool, atau Flatpak.

## Isi proyek

```text
.
├── index.html              # Halaman portfolio
├── assets/
│   ├── css/style.css        # Tampilan responsif
│   ├── js/script.js         # Menu ponsel, animasi, salin email
│   └── images/favicon.svg   # Ikon situs
└── .nojekyll               # Memastikan GitHub Pages menyajikan file statis apa adanya
```

## Publikasikan ke GitHub Pages

Paling mudah, buat repository baru bernama **`I4MMRMDH.github.io`** di akun GitHub `I4MMRMDH`. Dengan nama ini, alamat akhirnya menjadi:

`https://i4mmrmdh.github.io/`

Lalu lakukan langkah berikut:

1. Di halaman repository GitHub, pilih **Add file → Upload files**.
2. Unggah seluruh isi folder proyek ini: `index.html`, folder `assets`, file `.nojekyll`, dan `README.md`. Pastikan `index.html` berada di paling atas repository, bukan di dalam folder tambahan.
3. Tekan **Commit changes**.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch **main**, folder **/(root)**, lalu tekan **Save**.
7. Tunggu sekitar 1–3 menit, kemudian buka `https://i4mmrmdh.github.io/`.

Jika memakai nama repository lain, misalnya `portfolio`, alamatnya akan menjadi `https://i4mmrmdh.github.io/portfolio/`.
